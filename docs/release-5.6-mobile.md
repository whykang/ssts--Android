## 相比 5.5 的程序更新

### 播放与目录

- 安卓、iOS 增加 WMA 播放支持，兼容无扩展名的网盘音频链接，支持拖动与每集独立进度恢复。
- iOS 修复 WMA 切回上一集时卡住的问题；低采样率 WMA 转换为 48 kHz 输出，提高播放兼容性。
- 自动续播下一集从 00:00 开始，不读取旧断点或跳过片头；手动选集、上一集和下一集仍恢复各集进度。
- 点击已听完的章节会从头重播，不会立即跳到下一集。
- 详情页和播放页目录显示每集“听至 xx:xx”或“已听完”。
- 定时关闭增加自定义时长。

### 云同步与封面

- 每集收听进度和完成状态支持跨设备同步。
- 手动搜索选择、本地上传的封面支持同步；图片上传后再发布书籍引用，其他设备下载校验后应用。
- 网盘后来新增封面图片时，刷新目录可更新自动封面；用户手动选择的封面保持优先。
- 新增“同步插件”开关，默认关闭。开启后同名插件按版本保留高版本，下载安装缺失插件或更高版本。
- 插件删除也参与同步：离线保存删除记录，其他开启插件同步的设备同步时删除旧副本，不会将其重新上传复活；明确重新导入同名插件可恢复。
- 插件同步格式已升级，其他设备需更新到支持删除同步的版本。书架、书签和进度同步保持兼容；登录凭证和网盘账号不随插件同步。

### MCP 插件开发

- 安卓、iOS 支持局域网 Streamable HTTP MCP；设置中开启后连接显示的地址，不需要配对令牌。
- 提供读取指南、列出插件、读写草稿、校验、测试、安装、备份恢复和导出 ZIP 共九个工具。
- 服务默认关闭；开启服务时默认允许远程安装，可在设置中关闭安装权限。地址可点击复制，并分别显示局域网与本机地址。
- iOS 开发时需保持应用前台，可选择保持屏幕常亮；进入后台后关闭 MCP 服务。
- 内置指南更新为四端通用，直接提供完整书籍源、音频解析、搜索验证、增量更新及电台回听按日期分组、同日时间排序示例，AI 无需打开外部示例文件。

### 搜索验证

- 验证页已经显示书籍结果时直接返回应用，减少重复请求和长时间空转。
- 改进 iOS 囧贼等旧插件的验证结果识别、Cookie 同步及取消操作。
- 安卓验证页的取消、完成按钮适配状态栏，避免按钮位置过高。

## 插件合集 5.6

- 新增 **悦听有声书**，合集由 37 个源增加至 38 个。
- 悦听支持分类浏览、封面、目录及音频解析，不参与搜索；部分音频按原站多集合并的文件展示。
- 更新部分搜索验证接口，便于新版应用直接接收验证页结果。
