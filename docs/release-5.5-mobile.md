# 随身听书 5.5（Android / iOS）

## 下载与插件导入

- **Android 5.5**（Android 7.0 及以上）：[ssts-v5.5.apk](https://github.com/whykang/ssts--Android/releases/download/v5.5/ssts-v5.5.apk)
- **iOS 5.5**（iOS 16 及以上，未签名）：[ssts-ios-5.5-unsigned.ipa](https://github.com/whykang/ssts--Android/releases/download/v5.5/ssts-ios-5.5-unsigned.ipa)
- **插件包 5.5**（37 个源，Android / iOS 通用）：[Sources-v5.5.zip](https://github.com/whykang/ssts--Android/releases/download/v5.5/Sources-v5.5.zip)
- **国内插件直链**：https://gitee.com/whykan/ssxz/raw/master/Sources-v5.5.zip

在应用的“插件”页选择从网址导入，粘贴上面的国内直链即可；也可以下载 ZIP 后从文件导入。导入新版插件可覆盖旧版。

iOS IPA 需要使用自己的证书或签名工具签名后安装，不是可直接安装的 App Store 包。本次已完成 Release 真机架构构建与包结构检查，尚未完成 iOS 16 真机回归。

## 程序更新

- **每集独立保存播放进度**：第一集听到 12:30，第二集听到 05:00，切回各集时分别从各自的位置继续。
- **手动更换封面**：详情页菜单新增“更换封面”，可修改关键词搜索不同来源的封面，也可从本地选择图片；搜索期间即可选中候选，手动选择独立保存，不被目录刷新覆盖。
- **书籍状态**：支持手动设置连载或完本、跟随来源；完本且已有目录缓存时不自动刷新，没有缓存时正常加载，手动刷新仍然可用。
- **广播回听按日期分组**：便于按天查找节目，兼容旧插件；普通小说目录保留原有分段。
- 插件空白页的导入入口可选择从文件导入或从网址导入。
- **后台任务优化**：降低普通后台检查频率，暂停且无待处理任务时停止轮询；播放期间每 30 秒保存进度，暂停、切集等操作立即保存。定时关闭、跳过片尾和音量渐弱阶段保留必要检查精度。
- iOS 静音检测改为仅在开启“跳过静音”且实际播放时运行，并改进拖动进度的提交、等待与结果校验。

## 插件更新

- 新增 **听听 FM**：北京电台直播、节目搜索和历史回听；历史范围可选 7 天、30 天、90 天或全部，以来源实际提供的内容为准。
- 广播回听章节提供日期和时间信息，配合新版应用按日期分组，同时兼容旧版应用。

本程序只是播放器，不提供任何内容。音频来自插件访问的第三方网站或用户自己的网盘、文件，请支持正版，并只导入可信插件。
