# 插件云同步

安卓手机、iOS、Mac：设置 → 云同步 → 同步插件。开关默认关闭，且只保存在本机，
不会因为其他设备开启而自动开启。开启时弹窗提示“默认保存最高版本的插件”。
需要配置现有 WebDAV 账号；自动同步沿用打开应用、暂停播放、前后台切换的原有时机，
也可点击“立即同步”。不开启此项时，不读取或写入插件索引与插件包。

## 合并规则

- 仅同步用户导入的插件包；不包含内置电台、网盘源、本地源，也不传输插件偏好、Cookie、登录凭证或网盘账号。
- 使用 `manifest.json` 的 `name` 识别同名插件，使用 `version` 比较版本。插件包需有清单；未声明版本按空版本处理。
- 数字段按数值排序，例如 `1.10 > 1.9`，`5.5 == 5.5.0`；稳定版优先于相同主版本的预发布版，忽略 `+` 后的构建信息。
- 云端更高或本机缺失：下载、校验包，再通过现有插件安装流程安装。本机更高：上传本机包。低版本不能覆盖高版本。
- 同版本保留云端现有包，不反复上传，也不替换本机同版本内容。修改脚本后请提高清单版本号，其他设备才会收到更新。
- 开启插件同步后，手动删除会保存删除记录，并立即尝试同步；离线时保留记录，联网同步后从云端有效列表移除，其他开启此项的设备也删除本机副本。
- 删除记录优先于旧副本的版本号，旧设备即使留着更高版本也不能使插件复活。书架、书签和源偏好保留。
- 开启插件同步时手动重新导入同名插件视为恢复；恢复后在新的有效版本范围内继续采用最高版本规则。
- 关闭插件同步时删除只影响本机，不产生云端删除记录。关闭开关本身不删除任何插件。
- 插件重新加载与安装操作串行，避免启动时旧加载结果覆盖新插件。
- 同步开始后若插件目录被其他安装操作更新，以实际打包清单的版本再次比较，避免旧元数据造成降级。

## 存储及失败处理

使用同一 WebDAV 根目录下的独立文件，不改变旧版的书架、封面和进度同步格式：

- `ssts/plugins-sync.json`：`{"schema":2,"plugins":{"插件名称":{"version":"1.10","sha256":"…"}},"events":{"插件名称":{"time":1790000000000,"deleted":false,"barrier":0}}}`。
- `ssts/plugins/<sha256>.zip`：按包内容哈希保存的不可变 ZIP；先发布包，再发布引用它的索引。

只比较索引和本机已加载版本；需要上传时才打包，版本未变不压缩、不上传整个包。
普通同步沿用原来的节流，不增加定时轮询。手动安装、删除会尝试立即同步，进行中的同步会被本机新操作取消并排队重试。每包最多 32 MB，索引最多 256 个有效插件、1024 条变更记录。
索引只保留每个同名插件的最高版本；旧 ZIP 对象暂不自动删除，以免影响其他设备正在进行的同步。
下载校验 SHA-256，并核对包内清单的名称与版本；脚本通过加载校验后才替换旧插件。
安装串行执行，使用独立临时目录，替换失败恢复备份。失败在原有云同步状态中显示。

索引更新使用 WebDAV 强 ETag 与 `If-Match`；首次创建使用 `If-None-Match: *`。
并发冲突最多重新读取合并三次。服务器已有索引但未提供 ETag 时，拒绝覆盖索引，
以免把其他设备的高版本覆盖掉；书架同步格式与流程仍保持兼容。
兼容读取原 `schema:1` 索引；更新发布为 `schema:2`。只支持格式 1 的旧客户端将拒绝格式 2 的插件索引，需升级后才能继续插件同步，避免旧客户端重新上传已删除插件；书架同步不受此格式升级影响。

变更记录以同名插件的最后一次显式安装/删除时间合并，同时间删除优先；删除边界 `barrier` 保留，防止删除前的高版本穿过恢复操作复活。最高版本比较仅作用于当前有效范围。
本机记录保存在 `plugin-sync-events-<服务器和账号哈希>.json`，与 WebDAV 服务器和账号隔离；收到的删除记录持久保存，关闭应用或同步失败也不丢失。同步过程中固定目标账号，避免切换账号时把记录写到另一个云盘。
旧 ZIP 对象保留用于并发读取安全；删除针对云端有效列表及各设备安装副本，不在此功能中直接清理不可变历史对象。

TV 不注册安卓手机端插件同步扩展，没有新增设置，未修改或构建 TV 项目。

## 验证

`PluginCloudSyncTest`：关闭后零插件请求，首次上传、无变化不重复上传、数值版本排序、
预发布版排序、低版本不能覆盖高版本、缺失插件恢复、412 并发重试、删除与旧设备高版本上传冲突、防止删除后复活、明确重新导入恢复、关闭同步仅本机删除、不同服务器记录隔离、损坏包校验失败，以及有效哈希但脚本损坏时不替换旧版。

`scripts/tests/plugin-sync-dav.py` 提供本机隔离 WebDAV 服务（测试账号 user/pass），支持
ETag 和条件写入；Mac 两套独立应用数据验证上传、下载、1.8 恢复到 1.9、1.10 覆盖 1.9。
iOS 模拟器从 Mac 上传的包成功校验安装。两份 Apple 调试应用的 `pluginversions` 命令
验证相同的八组版本排序规则。三端编译通过；未使用真实云盘账号。

删除同步跨端回归：Mac A 发布删除后，Mac B 和 iOS 模拟器均移除本地 99.0 旧副本；
Mac A 明确重新导入 1.0 后，其他客户端可接收恢复，旧删除前的高版本不会复活。
安卓额外验证删除时遇到 412 冲突，仍能保留删除；不同服务器的记录不互相影响。
